# Project JARVIS：赛博造物

**为人的想象，构建第二具身体。**

> 当人工智能开始拥有双手，我们希望被放大的，是每一个人的创造力。

人的想象，常常先于身体抵达未来。

我们可以在脑海中构造一座尚不存在的建筑，想象一件从未被制造的物品，设计一种还没有发生的生活。然而，从一个念头到一件真实的作品，中间横亘着知识、技能、工具与时间。一个人能够想到的，往往远远超过他能够亲手完成的。许多构想因此停留在草图里、屏幕上，或某次没有继续下去的尝试中。

从这个角度看，工具的发展，也是人类不断为意志寻找新身体的过程。杠杆延长了力量，望远镜延长了视线，计算机扩展了计算与表达的能力。每一次工具的进步，都让人能够触及原本无法触及的事物。今天，具身人工智能让一种新的可能进入我们的视野：人的想象，能否获得一套能够理解意图、参与推演并作用于现实的行动能力？

这正是 Project JARVIS 希望探索的命题：**赛博造物——让个人的创造意图，通过人工智能与机器的协作，获得改变物理世界的能力。**

在科幻作品中，个人实验室是一种极具吸引力的空间。一个人站在工作台前，表达构想，与智能讨论方案，借助机器不断制作和修正；想法在对话、图像与实物之间流动，最终成为能够被触摸的存在。这个画面令人向往，因为它把构想与实现连接在同一个人的创作过程中。个人可以调用超出自身双手的能力，持续推动自己的想法成形。

JARVIS 希望追问的，是这种创造能力能否逐步走近普通个体。未来的学生、工程师、创客与独立开发者，能否拥有一张理解自己正在做什么、能够接续自己工作的智能工作台？当一个人说“我想试试这个想法”，他的身边能否出现一套与他共同观察、讨论和行动的系统，使这个念头有机会进入现实？

我们由此借用赛博朋克的一种问题意识：**在被强大技术包围的世界里，个体能够拥有多大的行动空间？**

一座高度自动化的城市，仍然值得为一张个人工作台保留位置。一个技术密集的未来，也应当容纳普通人改造工具、试验想法和亲手制作的生活。在 JARVIS 的愿景中，未来实验室可以成为个人创造力的延伸。人能够用自己的语言提出要求，用自己的判断选择方向，并借助智能与机械，在身边的物理世界中实现一点原本只能想象的变化。

我们将这一愿景称为“个人造物时代”：让更多人有机会参与现实的设计与制作，让技术能力逐步转化为个体可以使用的创造能力。这是项目希望靠近的未来方向，也是“赛博造物”这一概念的人文立场。

为此，JARVIS 被设想为人的**第二具创造身体**。人的经验、兴趣与审美为它提供方向；人工智能协助理解和推演；机械装置将构想落实为动作；真实世界的反馈又回到人的观察与判断之中。人的意图沿着这条链路向外延伸，触及自身双手之外的操作能力。创作也由此成为一个持续的过程：提出、尝试、看见结果，再产生新的想法。

这一关系的意义，在共同修改作品时尤其清晰。创作者的想法往往随着动手而生长，一处临时调整可能成为整件作品最重要的设计。当人说“保留我刚才改好的部分，再继续完成其他地方”，他表达的是对作品的判断，也是对自己劳动的确认。JARVIS 希望让这种确认持续影响后续行动，使机器的参与能够接续个人已经作出的选择。

因为一件作品的价值，也来自它承载了谁的经验、经过了怎样的取舍、留下了哪些亲手尝试的痕迹。即使机器能够承担越来越多的操作，人仍然需要在作品中认出自己。那些被保留的细节，构成了创作者与作品之间的联系：**这里面有我的想法，有我的决定，也有我留下的改变。**

因此，“赛博造物”所追求的，是创造能力与创作主体性的共同扩展。人可以获得更强的行动能力，同时继续决定什么值得创造、哪些细节值得保留、作品应该向何处生长。机器带来的力量，进入人的创作过程；人的个性与判断，也进入机器所执行的每一次改变。

本项目将从一张桌面开始，为这一愿景制作一个能够被观察和检验的微缩原型。积木成为最初的创作材料，屏幕与实物共同构成工作空间，机械臂承担具体行动。我们拟围绕同一件作品，连接语言表达、方案讨论、人工修改与实体执行，探索人与智能如何共同推动一个构想逐步成形。

这张桌面所承载的，是一个更大的研究问题：**当智能具备行动能力，它能否使一个人实现更多属于自己的想法？**

我们希望用连续的共创过程，为这个问题提供最初的回答。一个想法能够被接住，一次亲手修改能够被延续，一件作品能够在人的判断与机器的帮助中逐渐完成。未来的设计工作台、个人工坊与实验室辅助空间，可以从这样的协作关系中继续生长。

JARVIS 指向的未来，是个人与技术之间一种更有创造力的关系。人拥有想象，智能参与推演，机器贡献行动，而作品成为三者相遇后留在现实中的痕迹。一个人因此有机会成为身边现实的作者，让尚不存在的事物，因为自己的构想而出现。

**人的身体有边界。我们希望，人的创造力能够继续向外生长。**

**Project JARVIS：让想象获得双手，让个体成为现实的作者。**
