**建议主题：赛博造物——为人的想象构建第二具身体**

**核心表达：让想象获得双手，让个体成为现实的作者。**

## 全文主线建议

“赛博造物”可以定义为：**让个人的创造意图，通过人工智能与机器的持续协作，获得改变物理世界的能力。**

这一定义对应三个贯穿全文的层次：

| 叙事层次 | 人的需要 | 项目的回应 | 在报告中的位置 |
| --- | --- | --- | --- |
| **让想象获得双手** | 把尚未成形的想法带入现实 | 用语言讨论方案，并由具身系统实施实体修改 | 背景中的能力边界；目标中的意图到行动；创新中的共创闭环 |
| **让创作持续生长** | 在尝试、改主意和亲手操作之后继续推进作品 | 记住创作过程，结合新场景接续任务 | 背景中的创作连续性；目标中的多轮协作；创新中的记忆与适应 |
| **让作品保留人的痕迹** | 自己的选择和劳动能够留在最终作品中 | 将人工贡献与保留要求纳入后续编辑 | 背景中的个人主体性；目标中的成果保全；创新中的保护性局部编辑 |

建议将“个人造物时代”作为长期愿景，将“微缩未来实验室”作为产品形态，将“共创、共忆、共适、共护、共验”作为能力说明。这样，宏大命题、产品体验与工程研究之间有清晰的对应关系。

全文可以围绕这一问题展开：

> **当智能具备行动能力，它能否使一个人实现更多属于自己的想法？**

## 1. 背景需求调研建议

### 1.1 从人的能力边界引出赛博造物

人的想象，常常先于身体抵达未来。我们可以在脑海中构造尚不存在的建筑、器物与生活，却需要跨越知识、技能、工具和时间的距离，才能让其中一部分进入现实。一个人能够想到的，往往超过他能够亲手完成的。JARVIS 希望从这一距离出发，探索人的创造力如何借助智能与机械向外延伸。

工具的发展，可以被理解为人类不断扩展行动能力的过程。具身人工智能进一步带来一种可能：人的语言、设计选择和修改意图，能够经过理解与协作，成为真实世界中的行动。本项目将这一方向概括为“赛博造物”，并以桌面共创探索它的初步形态。

### 1.2 从科幻中的个人实验室引出产品愿景

《钢铁侠》中的 JARVIS 提供了一种鲜明的未来工作空间想象：个人站在工作台前，表达构想、讨论方案、观察预演，再借助机器完成制作。这个场景的吸引力，在于一个人的想法能够调动超出自身双手的观察、推演与行动能力。

Project JARVIS 希望将这种想象转化为一间微缩未来实验室。用户、屏幕、相机、机械臂和实体作品围绕同一张桌面协作，使构想能够在语言、数字方案与实物之间持续流动。个人工作台由此成为创造力向现实延伸的接口。

### 1.3 以赛博朋克的问题意识引出个体价值

建议将赛博朋克作为讨论人与技术关系的视角：在被强大技术包围的世界里，个体能够拥有多大的行动空间？一座高度自动化的城市，仍然值得为一张个人工作台保留位置；一个技术密集的未来，也应当容纳普通人试验想法、改造工具和亲手制作的生活。

JARVIS 所向往的“个人造物时代”，是更多人能够借助智能与机器参与现实的设计与制作。这里的人文关怀指向个人能力的扩展：让创作者能够做出更多属于自己的东西，并在作品中保有自己的审美、判断与经历。

### 1.4 将宏大愿景收束为持续实体共创的需求

真实创作往往在动手过程中逐步展开。一次试色会带来新的判断，一处亲手调整可能改变后续设计，一句“这里先保留”会成为下一步行动的条件。作品因此同时承载当前状态与形成过程。

如果系统只根据当前指令生成一次动作，就可能遗漏先前的选择和人工贡献。面向持续实体共创，需要把“接下来做什么”“刚才发生了什么”以及“哪些成果应当保留”连接起来。JARVIS 拟围绕这三个问题组织协作，让新的想法能够在已有作品上继续生长。

建议由此提出三类需求：

- **表达与实现相连接：**用户能够从设计意图出发，由系统协助组织具体操作。
- **创作过程可延续：**用户改变想法或亲手介入后，系统能够结合新的作品状态继续工作。
- **个人贡献可保留：**创作者认可的部分持续影响后续规划，减少无关改动与返工。

这些是拟研究的需求与价值假设；若要写成普遍存在的用户痛点，应补充访谈或观察依据。

### 1.5 目标人群与代表性场景

建议统一面向工程学习者、学生创客和个体开发者，以“围绕同一件实体作品持续设计与修改”为核心场景。开题报告和演示均使用“创作者”作为主角。

代表性任务可保留“共同设计未来基地”：创作者提出方向，JARVIS 给出有限的候选布局；用户选择并亲手修改局部，再要求系统继续完成其他部分。未来基地提供科幻氛围，固定网格上的积木作品提供可观察的研究环境。

### 1.6 项目价值与研究落点

建议用以下段落收束背景：

> JARVIS 希望为人的想象构建第二具创造身体。人的经验与审美决定方向，智能参与理解和推演，机械装置贡献行动，真实结果又回到人的观察与判断中。本项目从一张桌面出发，探索个人如何在机器的帮助下持续实现自己的想法，并让亲手作出的选择留在作品之中。桌面共创由此成为“赛博造物”的一个有限而可检验的工程起点。

对应的研究价值集中于意图到实体变化的衔接、多轮任务的持续接续，以及人工贡献在后续编辑中的保全。未来个人工坊与设计工作台可作为延伸方向。

## 3. 项目目标与内容建议

### 3.1 总体目标：构建个人创造力的具身延伸

建议将总体目标写为：

> 本项目拟构建面向个人创作者的 JARVIS 桌面具身共创工作台，以“赛博造物”为产品愿景，连接自然语言意图、共同方案形成与实体操作。系统围绕同一件作品持续协作，能够接续人工修改、保留既有贡献，并根据真实结果调整后续行动，使人的构想在讨论与实践中逐步成形。

“第二具身体”用于表达能力延伸的愿景；本阶段的产品目标是可运行的桌面原型，研究目标是验证持续协作机制的作用。

### 3.2 三项核心目标与背景逐项对应

| 核心目标 | 拟形成的产品能力 | 代表性验证 |
| --- | --- | --- |
| **让想象获得双手** | 用户以自然语言表达修改意图，系统形成可讨论的方案并完成实体操作 | 对指定区域移动或换色，检查实物结果是否符合要求 |
| **让创作持续生长** | 系统保存目标与进度，在人工修改或场景变化后接续同一创作任务 | 暂停、人工调整、重新观察、更新方案并继续执行 |
| **让作品保留人的痕迹** | 人工贡献和保留意图进入后续编辑约束 | 完成屋顶修改，同时保留用户已调整的窗户 |

### 3.3 保留原有基础目标与课程验收

建议保留原稿的五项基础任务，以及已纳入项目计划的人工修改历史和编辑策略比较，避免叙事调整改变交付要求。

| 基础目标 | 保留的内容 |
| --- | --- |
| 桌面识别 | 固定网格、三色同尺寸轻质积木，拼图／备料／回收区；至少两种初始图案；表示对象、颜色、位置与占用 |
| 语言理解 | 至少支持移动和颜色替换；校验格式、对象与位置；对缺失目标和含糊指代进行澄清 |
| 局部规划 | 生成修改清单，支持保护区、预览、确认和取消；处理占用、库存与保护冲突 |
| 实体执行 | 完成受控抓取、搬运、放置与等待；人机轮流操作，执行后核对实物 |
| 测试与分析 | 不少于 20 条独立测试指令、不少于 10 次真机局部编辑；报告解析正确率、实际编辑成功率和非目标区域误改 |
| 人工历史 | 记录可靠的人工变化，支持“刚才那块”等指代，并维护可调整的保护标记 |
| 策略比较 | 对照整体重排、当前布局差分、加入人工修改保护的局部编辑 |

测试指令应与提示词示例分开；最低测试数量用于课程交付，具体性能门槛在预实验后确定。

### 3.4 以持续共创组织增强目标

建议保留原稿中的六项增强能力，按产品体验表达：

1. **共同提出方案：**根据材料与用户偏好给出有限候选，接受选择与修改。
2. **跨回合推进：**维护长期目标、已核验进度和剩余任务。
3. **接续人工创作：**在安全暂停后的人工回合结束时，更新场景与后续方案。
4. **保留与恢复布局：**关联人工贡献与历史版本；历史布局恢复作为进阶能力单独验证。
5. **应对有限异常：**在至少一种已验证的异常类型中，实际完成观察、调整、再次执行与核验。
6. **形成连贯体验：**将提案、执行、人工修改和结果说明组织成一次连续共创。

人工历史、基本接续和有限恢复与课程主要交付相衔接；复杂候选生成、历史布局恢复和更长任务可按实际进展增强。

### 3.5 将价值主张转化为研究问题

| 研究问题 | 建议证据 |
| --- | --- |
| 自然语言意图能否落实为正确的实体变化？ | 指令解析、编辑成功、实物核验与失败环节 |
| 加入记忆与反馈后，人工介入或中断后的任务能否更好地接续？ | 相同动作模型与可比条件下的接续完成、重复操作、异常恢复和纠正次数 |
| 人工历史与保护机制能否减少对既有贡献的无关改动？ | 三种编辑策略下的额外搬动、非目标变化和用户再次纠正 |

主动参与设计与为修复系统失败而接管应分别记录。若希望进一步论证“增强掌控感、降低表达负担或改善创作体验”，可补充用户评价；机械操作指标主要回答系统行为是否改善。

> JARVIS 的技术方案围绕个人意图如何持续作用于实体作品展开。语言与交互提供表达入口，Agent 与记忆维护创作过程，ScenePatch 组织局部变化，视觉与动作模块连接真实环境，核验结果再进入下一轮决策。各模块共同支撑“表达—讨论—行动—观察—继续创作”的循环。

- **模型路线：**按当前仓库写为 π0.5＋LeRobot PyTorch LoRA；训练与本项目真机推理仍需分别验收。

## 5. 项目创新点及优势建议

建议将创新组织为三项拟研究的系统与交互贡献，与背景和目标逐项对应。“共验”作为贯穿三项贡献的验证基础。“赛博造物”承担总体叙事，具体创新由下面的机制与证据支撑。

### 5.1 让想象获得双手：面向个人创作的意图到行动协作闭环

**对应能力：共创。**

围绕一件正在形成的作品，将自然语言表达、方案提议、用户选择和实体编辑连接起来。创作者能够从希望作品发生的变化出发，与系统共同确定下一步行动。

建议突出本项目对协作流程的整合：同一设计意图如何贯穿对话、预览、动作与实际结果。采用现有语言模型和 VLA 的部分，应明确为技术基础；团队贡献集中于面向实体共创的交互组织与系统实现。

**建议验证：**记录从用户表达、方案调整到实物结果的完整过程，报告任务完成与各环节失败，展示用户意见如何影响最终行动。

### 5.2 让创作持续生长：融合人工历史的任务记忆与动态接续

**对应能力：共忆、共适。**

将用户目标、人工修改、已完成进度与当前场景共同纳入任务管理，使系统能够在多轮创作中接续工作。用户亲手介入后，系统依据新状态更新剩余操作，让正在变化的设计意图继续影响任务。

建议把研究重点放在“创作上下文是否能够跨回合发挥作用”。在相同动作模型与可比任务条件下，比较基础编排、加入记忆、加入核验恢复的表现，区分任务组织改进与动作模型能力变化。

**建议验证：**人工改动后的接续完成、过期计划拦截、重复操作、有限异常恢复及纠正次数。历史布局恢复可作为进一步增强，单独报告适用条件。

### 5.3 让作品保留人的痕迹：人工贡献感知的保护性局部编辑

**对应能力：共护。**

将可靠识别的人工修改及用户明确的保留要求转化为持续有效的编辑约束。系统在达成新目标时，尽量减少无关移动，使创作者已经认可的部分能够留在作品中。

这一点最适合承接项目的人文价值：一次人工调整同时具有物理变化和设计选择的意义。系统通过记录、保护与局部规划，让人的贡献实际影响后续行动。实现层面可沿用 ScenePatch 的状态差分、保护约束与执行顺序规划。

**建议验证：**在相同模型、视觉与机械臂接口下，对照整体重排、当前布局差分和加入人工保护的局部编辑，比较额外搬动、非目标区域变化与再次纠正。各组保留必要的停止与工作空间安全边界；当任务要求保护区域时，将该要求纳入统一评价。

### 5.4 共验：以真实作品检验协作是否成立

建议将视觉核验作为上述三项创新的共同基础：既检查要求的变化是否发生，也检查应保留的部分是否保持。只有真实结果满足条件，才更新已完成进度。

这样，“创造力的延伸”有了可观察的行为证据：想法得到落实，过程得以接续，个人贡献得到保留。至于创造力或主观体验是否提升，应在相应用户研究后形成结论。

### 5.5 建议用于答辩的创新概括

> JARVIS 围绕个人创造力的具身延伸，探索三个相互连接的能力：让人的意图进入实体行动，让变化中的创作过程持续接续，让人工贡献在后续编辑中得以保留。我们用共创、共忆、共适与共护组织这些能力，并以共验检查它们是否真正作用于作品。
